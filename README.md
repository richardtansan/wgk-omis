# Walang Gutom Kitchen Management System (WGKMS) – Front-end prototype

Stitch screens consolidated into a navigable static project.

## Pages
- `index.html` – entry point (home dashboard)
- `home.html` – operations dashboard
- `volunteers.html` – volunteer management
- `volunteer-portal.html` – volunteer portal
- `donations.html` – donation management
- `inventory.html` – inventory management
- `analytics.html` – data dashboard
- `nationwide-analytics.html` – nationwide analytics screen (provisional duplicate)

## Run
Open `index.html` in a browser. External CDNs and remote image links in the original Stitch screens may require internet access.

## GitHub Pages
Upload the contents of this folder to the repository root. In Settings → Pages, deploy from `main` and `/ (root)`.

## Limitations
This is a static prototype. Guest/admin behavior is a client-side UI convenience only, not security. No backend, database, server authentication, or persistence of module records. Original screens' form and button behaviors remain subject to browser testing; do not use operational data until validated.
